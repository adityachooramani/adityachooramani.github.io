About

Aditya Chooramani
Mathura, India

I'm a final-year BCA student in Mathura, graduating in 2027. I got into programming because I wanted to know how websites get hacked, and I still work that way: I build something, deploy it, and then try to get past my own login.

Most of what I build runs on AWS or Azure. Once it works, I test it with the same scanners and proxies an attacker would use, and fix what turns up.

I've completed TCM Security's Practical Ethical Hacking course and I'm working through PortSwigger's Web Security Academy. I write about what I find on dev.to.
